# מחולל הצעות מחיר Improve-IT

מחולל סטטי להצעות מחיר בעברית, מבוסס על פורמט הצעת מחיר של Improve-IT.
הפורמט הראשון שמוגדר במערכת הוא `השכרת LMS עם לומדות מדף`, לפי הצעת דוגמה.

## פתיחה

מריצים שרת מקומי:

```bash
npm run serve
```

ואז פותחים את:

```text
http://localhost:4173/
```

אפשר לפתוח את `index.html` ישירות בדפדפן לעריכה, אבל כפתור `הדפסה / PDF` שמפיק PDF עם קישורים פעילים דורש שהשרת המקומי ירוץ.

## יצירת הצעה

1. בוחרים פורמט הצעה ועורכים את פרטי הלקוח, הלומדות, מספר העובדים במסלול, הנחות ותוספות מחיר.
2. עורכים את `רכיבי הצעת מחיר`: שם רכיב, עלות, הערות והאם הרכיב כלול במחיר. אפשר להוסיף רכיבים או לאפס לברירת המחדל של הפורמט.
3. מסמנים אילו סעיפים יופיעו במסמך.
4. במידת הצורך ממלאים את פרטי החותם ומחתימים את הלקוח באזור `חתימת לקוח`.
5. לוחצים על `הדפסה / PDF` כדי ליצור PDF עם קישורים פעילים בתוכן העניינים.

## פורמטים

התשתית בנויה סביב `templateId` כדי לאפשר מעבר בין פורמטים והוספת פורמטים נוספים בהמשך.
בחירת פורמט בממשק מעדכנת את סעיפי המסמך ואת ברירות המחדל המסחריות, בלי למחוק את פרטי הלקוח והתוכן שהוזנו.

- `lmsShelfRental` - השכרת מערכת LMS עם לומדות מדף, כולל תמחור מדורג, מחיר לעובד נוסף, הנחה מותנית, תנאים וחתימת לקוח.
- `shortCommercial` - הצעה מקוצרת עם רקע, פתרון, תמחור ותנאים.

## שמירה וטעינה

- `שמירה` שומרת את ההצעה הנוכחית בדפדפן.
- הגדרות פורמטים והצעות חתומות נשמרות מקומית אם Supabase לא מוגדר.
- לאחר חיבור Supabase, מאגר ההצעות החתומות והגדרות הפורמטים נשמרים בענן.

## קישור אישי וחתימה

- `קישור ללקוח` יוצר קישור אישי שמכיל את נתוני ההצעה ומעתיק אותו ללוח.
- פתיחת הקישור מציגה מצב לקוח: אזור חתימה בלבד לצד תצוגת ההצעה.
- לאחר חתימה ולחיצה על `שלח הצעה חתומה`, ההצעה נשמרת ב`מאגר חתומות`.
- אם Supabase מוגדר, המאגר נטען ונשמר בענן. אם לא, המערכת חוזרת אוטומטית ל-`localStorage`.

## חיבור Supabase

1. צרו פרויקט Supabase.
2. פתחו את `SQL Editor` והריצו את הקובץ:

```text
supabase/schema.sql
```

3. העתיקו מ-Supabase את `Project URL` ואת `anon public key`.
4. עדכנו את הקובץ:

```text
config/supabase-config.js
```

לדוגמה:

```js
window.IMPROVE_IT_SUPABASE = {
  url: "https://YOUR_PROJECT.supabase.co",
  anonKey: "YOUR_ANON_PUBLIC_KEY",
};
```

החיבור שומר:

- הצעות חתומות בטבלה `signed_quotes`
- הגדרות פורמטים בטבלה `template_settings`
- לוגואים של לקוחות בטבלה `client_logo_settings`
- יועצי מכירות והיועץ הנבחר בטבלה `salesperson_settings`

הערה: הקובץ `schema.sql` כולל מדיניות RLS פתוחה ל-`anon`, כדי שהאפליקציה הסטטית תוכל לקרוא ולכתוב. לפרודקשן מומלץ להוסיף אימות משתמשים או API צד-שרת.

## יצירת PDF מהטרמינל

אם Chrome מותקן במחשב:

```bash
npm run pdf
```

או עם קובץ נתונים ופלט מותאמים:

```bash
node scripts/render-pdf.mjs data/example-elhar.json output/example-elhar.pdf
```

לאחר יצירת ה-PDF, הסקריפט ממיר את קישורי תוכן העניינים לקישורי PDF פנימיים ישירים.

אם Chrome לא נמצא אוטומטית, אפשר להגדיר:

```bash
CHROME_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" node scripts/render-pdf.mjs
```
