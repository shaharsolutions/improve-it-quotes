# מחולל הצעות מחיר Improve-IT

מחולל סטטי להצעות מחיר בעברית, מבוסס על פורמט הצעת מחיר של Improve-IT.
הפורמט הראשון שמוגדר במערכת הוא `השכרת LMS עם לומדות מדף`, לפי הצעת אל-הר.

## פתיחה

פותחים את `index.html` בדפדפן. אין צורך בהתקנת חבילות.

## יצירת הצעה

1. בוחרים פורמט הצעה ועורכים את פרטי הלקוח, הלומדות, מספר העובדים במסלול, הנחות ותוספות מחיר.
2. עורכים את `רכיבי הצעת מחיר`: שם רכיב, עלות, הערות והאם הרכיב כלול במחיר. אפשר להוסיף רכיבים או לאפס לברירת המחדל של הפורמט.
3. מסמנים אילו סעיפים יופיעו במסמך.
4. במידת הצורך ממלאים את פרטי החותם ומחתימים את הלקוח באזור `חתימת לקוח`.
5. לוחצים על `הדפסה / PDF` ושומרים כ-PDF מתוך חלון ההדפסה של הדפדפן.

## פורמטים

התשתית בנויה סביב `templateId` כדי לאפשר מעבר בין פורמטים והוספת פורמטים נוספים בהמשך.
בחירת פורמט בממשק מעדכנת את סעיפי המסמך ואת ברירות המחדל המסחריות, בלי למחוק את פרטי הלקוח והתוכן שהוזנו.

- `lmsShelfRental` - השכרת מערכת LMS עם לומדות מדף, כולל תמחור מדורג, מחיר לעובד נוסף, הנחה מותנית, תנאים וחתימת לקוח.
- `shelfCoursesOnly` - לומדות מדף ללא LMS.
- `shortCommercial` - הצעה מקוצרת עם רקע, פתרון, תמחור ותנאים.

## שמירה וטעינה

- `שמירה` שומרת את ההצעה הנוכחית בדפדפן.
- `ייצוא JSON` מוריד קובץ נתונים של ההצעה.
- `ייבוא JSON` טוען הצעה קיימת.
- חתימה דיגיטלית נשמרת כחלק מקובץ ה-JSON ותופיע בהצעה לאחר טעינה מחדש.

## קישור אישי וחתימה

- `קישור ללקוח` יוצר קישור אישי שמכיל את נתוני ההצעה ומעתיק אותו ללוח.
- פתיחת הקישור מציגה מצב לקוח: אזור חתימה בלבד לצד תצוגת ההצעה.
- לאחר חתימה ולחיצה על `שלח הצעה חתומה`, ההצעה נשמרת ב`מאגר חתומות`.
- בשלב זה המאגר נשמר בדפדפן המקומי באמצעות `localStorage`. כדי לשמור חתימות במאגר חברה מרכזי יש לחבר את פעולת השליחה לשרת/API.

## יצירת PDF מהטרמינל

אם Chrome מותקן במחשב:

```bash
npm run pdf
```

או עם קובץ נתונים ופלט מותאמים:

```bash
node scripts/render-pdf.mjs data/example-elhar.json output/example-elhar.pdf
```

אם Chrome לא נמצא אוטומטית, אפשר להגדיר:

```bash
CHROME_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" node scripts/render-pdf.mjs
```
